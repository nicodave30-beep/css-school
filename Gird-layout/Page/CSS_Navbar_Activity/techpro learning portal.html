    What is html or css??

    HTML, which stands for HyperText Markup Language, is the standard text-based language used to structure and organize content on the World Wide Web. It acts as the skeleton of every webpage, telling web browsers how to display elements like text, images, buttons, and links

    CSS, which stands for Cascading Style Sheets, is a style sheet language used to define the visual presentation and layout of web pages. While HTML provides the raw structure and skeleton of a website, CSS acts as the design layer—controlling colors, fonts, spacing, layouts, and animations. Along with HTML and JavaScript, it forms one of the three core pillars of web development.

    W3 School

    W3Schools is a popular online platform that provides web development tutorials and references for various web technologies. It serves as a comprehensive resource for individuals who are learning or looking to enhance their skills in HTML, CSS, JavaScript, and other related technologies. The website offers a wide range of educational materials, including beginner-friendly tutorials, interactive examples, and hands-on exercises. These resources are designed to help users understand the fundamentals of web development and gain practical experience. Users can learn about topics such as web design, front-end development, back-end development, database management, and more. One of the notable features of W3Schools is its "Try it Yourself" editor, which allows users to experiment with code directly within their web browser. This interactive environment enables learners to test out different code snippets, modify them, and see the results in real-time, providing an effective way to practice and reinforce their understanding. In addition to tutorials, W3Schools also provides comprehensive references for various web technologies, which serve as handy guides for developers when they need quick information or syntax references. The platform covers a wide range of subjects, including HTML elements, CSS properties, JavaScript functions, SQL queries, and more. Overall, W3Schools is a well-regarded resource that has been utilized by numerous individuals seeking to learn web development concepts or refresh their knowledge. However, it's worth noting that while W3Schools is a valuable learning platform, it is not affiliated with the official World Wide Web Consortium (W3C), the international standards organization for the web."

    About Qhs

    History

    It was in 1955 when Quirino High School was established as an annex of Quezon City High School. There were 200 students and four mentors then. By virtue of a Council Resolution, Quirino High School became an independent school in 1958 with 20 faculy members and 883 students. Situated in-between the boundary of Brgy. Amihan in Banuyo St. and Brgy. Duyan-Duyan along Molave St. QHS caters more than 3,000 students coming from Brgy. Botocan, Daang Tubo and Marytown in Loyola Heights, Krus na Ligas, Brgy. Amorsolo in UP Diliman, Brgy. Pansol in Balara, Brgy. Tagumpay and Escopa in Project 4, Quezon City. It also extends its service as far as Montalban and San Mateo Rizal, Masinag and even a few students in Marikina. Majority of the students belong to the middle and the lower middle class. Thus, some of them would rather walk to augment their daily allowance particularly those coming from Katipunan Road. At present, Quirino High School, as a child friendly school envisions to improve in key result areas in basic education such as its access, quality and governance.
